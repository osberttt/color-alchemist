Colorchemy: the 55 colors

Every run deals 7 colors: 3 Lead, then 3 Silver, then 1 Gold, never two of the same element in a row and at most 2 dark ones. "% of runs" = how often a color appears in a run (simulated, 20,000 runs, tutorial done). Before this fix, Denim was also forced as the first color of every camera run until one camera run was finished.
